# ForgeWriter AI — Describe (Érzékletes Leírás) Feature Design

**Date:** 2026-06-09  
**Status:** Approved  
**Priority:** MVP  
**Session:** Brainstorming — Describe sensory feature design

---

## Summary

The Describe feature allows writers to select any text fragment in the manuscript editor and instantly generate evocative, sense-specific descriptions for it. Each sense channel produces an independent result card in the AI panel. Writers can selectively copy, insert, or star individual cards (which saves them as Snippets).

Inspired by Sudowrite's "Describe" feature, adapted for Hungarian-language fiction and extended with a ForgeWriter-specific "Érzelmi atmoszféra" channel (V1).

---

## Feature scope

### MVP (6 channels)

| Channel | Hungarian label | Key |
| --- | --- | --- |
| Sight | Látás | `sight` |
| Sound | Hang | `sound` |
| Touch | Tapintás | `touch` |
| Smell | Szag | `smell` |
| Taste | Íz | `taste` |
| Metaphors | Metaforák | `metaphor` |

All six channels are generated by default. V1 adds per-channel toggles.

### V1 additions

- **7th channel:** Érzelmi atmoszféra (`emotional_atmosphere`) — unique to ForgeWriter, generates the emotional and atmospheric texture of a scene moment rather than a physical sensation. Particularly useful for Hungarian literary fiction where interiority and mood carry narrative weight.
- **Per-channel toggles:** Writers can disable specific channels they don't need.
- **Sense toggle memory:** Last-used toggle configuration is remembered per project.

---

## Trigger points

### Primary — Selection bubble (Tiptap)

1. Writer selects any text in the manuscript editor (a word, phrase, or up to ~2 sentences).
2. Tiptap's floating bubble menu appears.
3. A `Leírás` button is visible in the bubble menu alongside Rewrite, Expand, etc.
4. Clicking `Leírás` triggers the Describe flow.

### Secondary — AI panel action

- An `Érzékletes leírás` action button is available in the AI assistant panel when a text selection is active in the editor.

---

## Context window

The API sends two pieces of context:

- **`selected_text`** — the highlighted phrase (typically 1–20 words; best results with short phrases)
- **`preceding_context`** — up to ~200 words immediately before the selection (auto-extracted by the frontend)

The preceding context provides narrative atmosphere so the AI generates descriptions consistent with the scene's tone and setting. It is never shown to the writer directly; it is transparently included in the prompt.

## UI flow (detailed)

```
Writer selects "a rozsdás kapupánt"
  ↓
Tiptap bubble menu appears → "Leírás" button visible
  ↓
Writer clicks "Leírás"
  ↓
AI panel transitions to "Leírás" mode
  ↓
Loading state: 6 placeholder cards with shimmer animation
  ↓
Results stream in one card at a time (Látás first, then Hang, etc.)
  ↓
Each card shows:
  - Sense icon + Hungarian label (e.g. 👁 Látás)
  - Generated text (2–4 sentences)
  - Actions: [Beillesztés ▾] [⭐ Mentés] [✕]
  ↓
Writer reads each card independently
  ↓
Option A: Click "Beillesztés" → dropdown: [Kurzorhoz] [Kijelölés után] [Kurzor előtt]
Option B: Select text WITHIN a card → inline "Beillesztés" micro-button appears
Option C: Click ⭐ → card saved as Snippet (linked to current scene)
Option D: Click ✕ → card dismissed
```

## Result card design

Each card is a soft-bordered, rounded surface in the AI panel:

```
┌─────────────────────────────────────────────┐
│ 👁  Látás                                    │
│                                              │
│  A vas rozsdafoltjai barnásvörös virágként   │
│  nyíltak szét a kapupánton, szélein          │
│  cafrangos, mint régi selyem.                │
│                                              │
│  [Beillesztés ▾]          [⭐]   [✕]         │
└─────────────────────────────────────────────┘
```

- Background: `aiMuted` (`#f0e9ff`)
- Border: `border` (`#ded8ce`)
- Sense icon: Lucide icon or emoji
- Insert button: primary action, small dropdown
- Star: saves as Snippet
- Dismiss: removes card from panel (does not delete anything)

## Snippet integration

When a writer stars a Describe result card, a Snippet record is created automatically:

```json
{
  "project_id": "uuid",
  "scene_id": "uuid",
  "title": "Látás — a rozsdás kapupánt",
  "content": "A vas rozsdafoltjai barnásvörös virágként...",
  "content_type": "describe_result",
  "source_sense": "sight",
  "tags": ["describe", "sight"]
}
```

Starred cards are then accessible from the Snippet panel, searchable by tag (`describe`, `sight` etc.) and by scene. This allows writers to build up a library of evocative fragments over time.

## API contract

### Endpoint

```http
POST /api/v1/ai/describe
```

### Request

```json
{
  "project_id": "uuid",
  "scene_id": "uuid",
  "selected_text": "a rozsdás kapupánt",
  "preceding_context": "Az utca végén megállt. Valami húzta visszafelé...",
  "senses": ["sight", "sound", "touch", "smell", "taste", "metaphor"],
  "model_preference": "local"
}
```

The `senses` array defaults to all six in MVP. V1 exposes this as a per-request parameter surfaced via the UI toggles.

### Response

```json
{
  "job_id": "uuid",
  "status": "requires_review",
  "results": [
    { "sense": "sight",    "label": "Látás",      "text": "..." },
    { "sense": "sound",    "label": "Hang",        "text": "..." },
    { "sense": "touch",    "label": "Tapintás",    "text": "..." },
    { "sense": "smell",    "label": "Szag",        "text": "..." },
    { "sense": "taste",    "label": "Íz",          "text": "..." },
    { "sense": "metaphor", "label": "Metaforák",   "text": "..." }
  ]
}
```

In MVP the full response is returned synchronously (no streaming). V1 may switch to SSE so cards appear progressively as each sense completes.

### GenerationJob record

A `GenerationJob` record is created with `job_type: describe`. The `input_json` stores the full request; `output_json` stores the results array. This provides a history of all Describe calls and supports the Revision model.

## Prompt template

Prompt lives at: `packages/prompts/hu/describe.md`

The prompt template receives:

- `{{selected_text}}` — the selected phrase
- `{{preceding_context}}` — up to 200 words before the selection
- `{{sense}}` — the target sense channel name (one prompt call per sense, or batched)
- `{{style_guide_summary}}` — optional, from the project's StyleGuide if available

The prompt instructs the model to:

1. Write 2–4 sentences in Hungarian literary prose
2. Evoke only the specified sense (no mixing with other senses in a single card)
3. Match the tone of the preceding context
4. Avoid overly ornate or anglicized sentence structures
5. Keep the description grounded in the physical reality of the scene

## Data model changes

### Snippet table additions

Two new fields on the `Snippet` table:

```sql
scene_id UUID nullable REFERENCES scene(id)
source_sense TEXT nullable  -- sight / sound / touch / smell / taste / metaphor / emotional_atmosphere
```

The `content_type` enum gains a new value: `describe_result`.

### GenerationJob job_type enum additions

```txt
describe
quick_edit
```

## Known risks and constraints

| Risk | Mitigation |
| --- | --- |
| Model may mix senses in one card | Prompt explicitly instructs single-sense focus; reviewer pass can flag violations |
| Hungarian literary quality may be poor with weak local models | Prompt includes style examples; writer can regenerate or ignore poor cards |
| 6 sequential LLM calls may be slow on local Ollama | V1: batch into single call or use SSE streaming so cards appear progressively |
| Selected text too long (paragraph+) | Frontend warns if selection exceeds 100 words; best results under 20 words |
| Snippet panel may fill up with low-quality describe results | Dismiss button removes card without saving; only starred cards become Snippets |
