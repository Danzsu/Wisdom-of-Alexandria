Sonner Toast notifications

A shadcn/ui hivatalos toast megoldása (ugyanaz a fejlesztő). Egyszerű, szép, nulla konfig.

ForgeWriterben használná:

  • „Jelenet mentve ✓"
  • „AI generálás elindult…"
  • „Export kész, letöltés indul"
  • „Continuity warning: Anna nem lehet itt"
  • „Ollama nem elérhető ⚠"
→ Ajánlás: MVP — toast nélkül az app süket
cmdk Command palette

Cmd+K command palette — shadcn/ui Command komponens alapja. Power user navigáció.

ForgeWriterben használná:

  • Gyors ugrás project / fejezet / jelenet között
  • Codex gyorskeresés
  • AI akció indítása: „Rewrite selected"
  • Model váltás gyorsan
  • Export indítása
→ Ajánlás: V1 — hasznos de nem blokkoló MVP-hez
Megjegyzés: cmdk már shadcn/ui dep — installálva lesz, csak a komponens kell

🔍 Radix UI — külön megemlítendő?

A shadcn/ui Radix UI primitívekre épül (Dialog, Dropdown, Select, Tooltip, Popover stb.). Ez automatikusan installálja a szükséges Radix csomagokat. Nem kell külön konfigurálni, de a package.json-ban explicit dependencyként szerepel majd. Ajánlás: a docs-ban megemlíteni mint "shadcn/ui alap", de nem külön stack elemként kezelni.
